# Proud Little Learners

This repository is a static website. The pages are HTML, CSS, and JavaScript at the repository root. No build step is required to open the site.

## Open it locally

Open `index.html` in a browser, or serve this folder:

```bash
python3 -m http.server 8000
```

Then go to [http://localhost:8000/](http://localhost:8000/).

## GitHub Pages

The publishing source for this site is the `main` branch at `/`. `.github/workflows/pages.yml` deploys those static files once GitHub Pages is enabled for the repository.
