Why the pages are set up this way

  • Where to start. Each pack lists what your child should already be able to do, so the new work sits just past that.
  • The parent prompt. It tells you when to count together and when to let your child finish.
  • The page order. Groups you can count, then a picture, then a number sentence.
  • The tracker. You mark whether to repeat a page or move on.

Questions parents ask

Which pack should we start with?

Beginner: Adding within 5, if your child can count to 10 and read numbers 0–5. Move on when that pack feels easy.

What if a page feels too hard?

Stop and step back, or count real objects first. The parent prompt says when to help.

What do I get?

A PDF to print at home, with activity pages, a parent prompt, an answer key, and a tracker. Page counts will be listed with the finished file.

How is weekly different from one pack?

Single pack: one level, $3.99 once, yours to keep. Weekly: a new kindergarten math packet every week for $3.99/mo, plus this month's packets right away, cancel anytime. Reading and other grades are coming next.
